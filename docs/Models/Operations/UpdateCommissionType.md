# UpdateCommissionType

The type of commission. Can be `click`, `lead`, `sale`, `referral`, or `custom`.


## Values

| Name       | Value      |
| ---------- | ---------- |
| `Click`    | click      |
| `Lead`     | lead       |
| `Sale`     | sale       |
| `Referral` | referral   |
| `Custom`   | custom     |
