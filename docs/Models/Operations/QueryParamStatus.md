# QueryParamStatus

Filter the list of partners by their status for your program. `discover` returns the partners that are not in your program and that you have not ignored, ranked by relevance.


## Values

| Name        | Value       |
| ----------- | ----------- |
| `Discover`  | discover    |
| `Invited`   | invited     |
| `Recruited` | recruited   |
| `Ignored`   | ignored     |
